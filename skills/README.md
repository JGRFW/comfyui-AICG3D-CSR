# CSR Replacement Skills

This directory contains the four first-class replacement skills exposed by the `CSR ③` convenience tag menu.

- [Single person](single-person.md)
- [Multiple people](multi-person.md)
- [Product / object](product.md)
- [Background / scene](background-scene.md)

`replacement_skills.json` is the machine-readable source loaded by ComfyUI route `/aicg3d_csr/replacement_skills`. The JSON and Markdown skills must remain aligned.

Editing the JSON and refreshing ComfyUI rebuilds the tag menu without changing Python or JavaScript node code.
