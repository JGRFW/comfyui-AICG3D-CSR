# 背景/场景替换 Skill

## 目标

彻底替换视频背景或场景，而不是调色、换壁纸、局部修补或保留旧房间结构。

## 素材设置

- 环境图上传到 `背景替换`
- 不要上传到人物/物品替换槽
- `参考/首帧` 在背景替换时不会用来锁住旧环境
- 环境图尽量使用清晰、无人物、无大面积水印的图片

## 提示词

```text
执行强制背景/场景替换，所有人物和指定保留物品保持不变。背景参考图是唯一环境来源，不是风格、颜色或光照参考。覆盖除前景人物和指定物品外的全部背景区域，完整继承参考图中的空间结构、墙体、地面、天花、门窗、家具、陈设、材质、颜色和光照。必须彻底删除原视频旧场景，不得保留旧房间布局、墙纸、家具轮廓或通过调色、模糊、局部修补伪装成新背景。新场景从画面四边到人物边缘连续铺满，人物头发、透明衣物、遮挡、脚底接触和接触阴影自然；不把参考图中的人物、文字、LOGO或水印带入成片。保持人物身份、服装、动作、口型、站位、镜头和时长不变。
```

## 失败后强制重试

1. 选择“修复：背景没有被替换”提示词方案。
2. 细节强度选择“强化”。
3. 缩短到 2–3 秒测试。
4. 在描述中写明“新环境必须清楚可辨，旧环境不能残留”。
5. 如果仍然失败，提高背景参考在提示词中的优先级，并降低人物/商品替换复杂度。

## 失败检查

- 只是墙面变色：继续强调删除原墙纸、家具和房间布局。
- 背景参考人物被生成：明确禁止带入参考图中的人物。
- 人物边缘出现旧背景：强调透明衣物、头发和轮廓边缘连续。
- 脚底悬空：强调地面透视、接触点和接触阴影。
