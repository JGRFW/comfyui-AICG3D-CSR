# 单人替换 Skill

## 目标

只替换一个明确指定的人物，同时保持其他人物、背景、物品和镜头内容不变。

## 素材设置

- `替换物 1` 类型：人物
- 只上传一个目标人物参考
- 不要为了换衣服额外上传不同身份的人
- 其余替换物留空

## 提示词

```text
仅执行单人身份替换。把替换物 1 中的人物作为唯一身份来源，替换视频中明确指定的一个人物；脸型、五官、发型、肤色、身体比例和服装严格来自替换物 1，旧人物身份不得残留。保留原视频背景、镜头运动、人物站位、身体动作、面部表情、口型、互动节奏、遮挡关系、光线和时长不变。不替换其他人物，不新增人物，不改变服装设计，不沿用参考图中的姿势、背景、文字或光线。
```

## 失败检查

- 如果多人被一起替换：强调“只替换明确指定的一个人物”。
- 如果背景被改变：检查是否误用了多人或多物品标签。
- 如果脸不像：缩短分段、提高参考图质量、关闭多人参考。
- 如果身份和动作冲突：降低更换 LoRA 强度，动作优先级设为源视频。
