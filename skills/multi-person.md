# 多人替换 Skill

## 目标

让多个替换物与视频中的多个指定人物一一对应，避免身份融合、串位和漏换。

## 素材设置

- 替换物 1、2、3 等分别上传不同人物
- 每个槽位选择“人物”
- 在主体绑定中明确写下每个人物的位置、服装、互动对象或前后层级
- 不要把同一人物重复上传到多个槽位

## 提示词

```text
执行多人身份替换。替换物 1、2、3 等分别绑定视频中明确指定的不同人物，每个人物只使用其对应参考图的身份、脸型、五官、发型、肤色、身体比例和服装。保持每个人物的独立身份，禁止身份融合、换脸串位、重复人物、漏换人物或凭空增加人物。严格保留原视频人物数量、站位、前后层级、遮挡、互动关系、身体动作、口型、镜头、背景、光线和时长。多人无法稳定完成时优先保持人数与动作正确，再保证身份细节。
```

## 绑定建议

```text
替换物 1 = 画面左侧、紫色衣服的女性
替换物 2 = 画面右侧、黑色衣服的男性
替换物 3 = 前景背对镜头、背红色背包的人
```

## 失败检查

- 身份互相混合：减少同段人数，拆成多个 CSR ③ 顺序执行。
- 只换到一人：降低 Character Swap LoRA 强度或拆分节点。
- 多出人物：提示词强调“不增加人物，不复制人物”。
- 人物位置互换：在绑定中写清左右、前后、服装和遮挡关系。
