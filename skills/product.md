# 商品替换 Skill

## 目标

只替换人物手持、佩戴或摆放在场景中的商品、产品、包装、背包或道具。

## 素材设置

- 上传商品正面、侧面或细节图到替换物槽
- 槽位类型选择“物品/产品”
- 商品文字和 LOGO 必须清晰
- 不把人物图误放进商品槽

## 提示词

```text
仅执行商品、产品或指定物品替换，所有人物和背景保持不变。商品参考图是唯一外观来源，严格继承轮廓、比例、尺寸、结构、颜色、材质、纹理、包装形状、LOGO、标签和可识别细节；不得重新设计商品，不得改写品牌文字，不得生成参考图中不存在的结构。商品必须贴合原握持位置、手部姿势、遮挡关系、透视、接触阴影和环境光线，避免漂浮、穿模、变形、闪烁、边缘融化或物体复制。保持原人物身份、动作、口型、镜头、背景和时长不变。
```

## 补充示例

```text
商品由右手握持，包装正面朝向镜头；手指遮挡关系与原视频一致，不改变包装上的品牌文字和颜色。
```

## 失败检查

- 商品变形：增加正面参考图，减少无依据的侧面推断。
- 文字被改写：明确“不得改写品牌文字或生成参考图外文字”。
- 商品漂浮：强调握持、遮挡、接触阴影和接触点。
- 商品复制：强调“只替换一个目标商品，不复制物体”。
