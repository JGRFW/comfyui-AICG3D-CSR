# CSR 替换提示词标签

`CSR ③ 逐段替换` 顶部提供“替换标签”。标签只描述任务类别；点击“应用模板”后，才会把对应提示词写入 `description` 输入框。这样不会在切换标签时覆盖已经手工修改的提示词。

CSR 后端会根据资源库中实际上传的素材角色再次判断任务。例如同时上传两个人、一个背景，却选择了“背景/场景替换”，条件提示词仍会自动按“人物 + 背景”执行，避免模型只做一个类别。

需要本地模型进一步扩写时，打开 `CSR ③` 的“提示词优化”，配置 Ollama、LM Studio、llama.cpp 或其他 OpenAI 兼容本地 API。背景替换失败时优先使用“修复：背景没有被替换”方案。详细配置见 [prompt-optimizer.md](prompt-optimizer.md)。

最常用的四项操作已经做成独立 Skill：`单人替换`、`多人替换`、`商品替换`、`背景/场景替换`。说明见 [skills/README.md](../skills/README.md)。

## 使用规则

1. 在 `MiniMax H3 Aicg资源库` 中上传参考图。
2. 每个 `替换物 1-7` 槽位必须选择正确类型：
   - 换人、角色、身体参考：`人物`
   - 换产品、背包、道具、手持物：`物品/产品`
3. 换背景时，把环境图上传到 `背景替换`。
4. 在 `CSR ③` 中选择标签，再点击 `应用模板`。
5. 模板写入后仍可继续补充位置、颜色、LOGO 文字、左右手或镜头段落等细节。
6. H3 单次最多使用 9 张图片参考。最多 7 张 `替换物` 加 `背景替换` 和 `参考/首帧`，正好覆盖这个上限。

## 人物替换

```text
仅替换视频中的目标人物。人物身份、脸型、五官、发型、身体比例和服装严格来自对应人物参考图；保持原视频的背景、镜头运动、人物站位、身体动作、口型、互动节奏、光线和时长不变。不增加原视频没有的人物或动作。
```

适合补充：

```text
目标人物始终位于画面左侧；参考图只提供身份和服装，不沿用参考图中的姿势、背景或光线。
```

## 背景/场景替换

```text
执行强制背景/场景替换。若资源库同时上传了人物替换参考，则指定人物和完整背景必须在同一次结果中同时替换；若没有人物参考，则所有人保持原样。背景参考图是唯一环境来源，不是风格、颜色或光照参考。覆盖除指定前景人物和物品外的全部背景区域，完整继承参考图中的空间结构、墙体、地面、天花、门窗、家具、陈设、材质、颜色和光照。必须彻底删除原视频旧场景，不得保留旧房间布局、墙纸、家具轮廓或通过调色、模糊、局部修补伪装成新背景。新场景从画面四边到人物边缘连续铺满，人物头发、透明衣物、遮挡、脚底接触和接触阴影自然；不把参考图中的人物、文字、LOGO或水印带入成片。有人物参考时，每个人都必须一对一使用自己的参考图，禁止只换一个人。
```

适合补充：

```text
新环境采用参考图中的完整房间结构，不能保留原视频的墙纸、家具轮廓或房间布局；人物脚底与新地面接触自然。
```

## 物品/产品替换

```text
仅替换视频中指定的物品或产品，人物保持不变。物品的轮廓、比例、颜色、材质、结构、LOGO 和细节严格来自对应物品参考图；保持原人物身份、脸部、发型、服装、手部姿势、动作、镜头、背景和时长不变。物品必须自然贴合原握持位置、遮挡关系和接触阴影，避免漂浮、穿模、变形和闪烁。
```

适合补充：

```text
目标物品由右手握持，位于画面中央偏下；替换后包装正面朝向镜头，手指遮挡关系与原视频一致。
```

## 多人 + 背景

多人加背景时，每个人物槽位只对应一个人。默认顺序按画面从左到右绑定，也可以在资源库的“主体绑定”中写明更准确的位置：

```text
替换物 1：画面左侧的小孩，使用参考图 1
替换物 2：画面右侧的小孩，使用参考图 2
背景替换：全画面完整环境
```

提示词应明确写“恰好两人都要替换，同时替换完整背景”，不能只写“替换人物和背景”这种笼统描述。多人同一次采样仍会受模型、LoRA 和参考图相似度影响；如果仍只换一个人，先检查人体绑定，再降低 Character Swap LoRA 强度或拆分顺序替换。

## 人物 + 背景

```text
同时强制替换指定人物和完整背景。每个人物必须一对一使用自己的参考图；如果指定两人，就必须同时替换两人，禁止只换主要人物、身份融合、复用参考或漏换。人物身份、脸型、发型、身体比例和服装严格来自对应人物参考图；背景参考图作为唯一环境来源，覆盖除指定前景之外的全部背景区域，完整重建空间结构、墙体、地面、天花、门窗、家具、陈设、材质、颜色和光照。必须清除原视频旧场景结构。保持原视频镜头、人物站位、动作、口型、互动节奏和时长不变。人物替换和新背景必须在同一结果中同时成立，不允许只完成其中一个任务。
```

## 人物 + 物品

```text
同时替换人物和指定物品/产品。人物外观严格来自人物参考图，物品轮廓、比例、颜色、材质、结构和 LOGO 严格来自物品参考图。保持原视频背景、镜头、人物动作、手部姿势、口型、站位和时长不变。物品必须自然贴合手部握持、遮挡和接触阴影，不改变未被指定替换的内容。
```

## 人物 + 背景 + 物品

```text
同时替换人物、背景和指定物品/产品。人物身份与服装来自人物参考图，环境来自背景参考图，物品外观与材质来自物品参考图。保持原视频镜头、动作、口型、站位、互动节奏和时长不变。人物与新背景的透视、光照和接触阴影自然一致，物品自然贴合手部姿势和遮挡关系，不引入参考图中无关的人物、文字、水印或物体。
```

## 自定义标签

选择 `自定义` 时不会改动现有 `description`。建议按以下顺序编写：

```text
替换目标 + 每个参考图对应什么 + 哪些内容必须保留 + 位置和遮挡关系 + 光线与透视要求 + 禁止新增或改变的内容
```

多人、多物品或复杂场景建议拆成多个 `CSR ③` 顺序执行。一次放入过多参考图会增加显存占用、采样时间和身份或结构串扰的风险。
